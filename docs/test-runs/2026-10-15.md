# 2026-10-15 真实场景测试（v0.1 → v0.2）

环境：macOS，Chrome 155，用户本人的登录态，所有操作都在 MCode 标签组里进行。

## 场景与结果

| 场景 | 站点 | 用到的工具 | 结果 |
| - | - | - | - |
| 搜索实时动态 | x.com/search（已登录） | goto, read_text | ✅ 8.7s 加载完成，正文完整 |
| 深度调研：搜索 → 打开文章 → 读全文 | bing.com → blog.frognew.com | goto, locate, click, read_text | ✅ 链接在新标签页打开（bug #2，已修） |

## 发现并修复的问题

1. **tab_open 立刻返回，URL 为空**：在初始的 about:blank 上就判定“已就绪”。修复：先建空白页，再走 goto 的完整等待流程。
2. **点击打开新标签页（target=_blank）时，结果里没有提示**：修复：点击期间监听新建的标签页，自动归进 MCode 组，等它加载完，并在结果里列出 tabId。
3. **组件在失焦后改写或清空字段值，fill_form 发现不了**：修复：全部字段填完后统一失焦，再整体回读一遍；值变了的字段标为 ✗，并给出处理建议。
4. **长连接站点（X 等）永远判定不了“加载完成”**：修复：只有构建页面的请求（Document、Script、XHR、Fetch、CSS、Font）计入网络空闲判定；超过 4 秒还没结束的请求视为长轮询；`interactive` 状态持续 3 秒也算加载完成。
5. **开发效率**：新增 `reload_extension` 和 `version` 工具，以后改完扩展代码不需要再手动点重载。
