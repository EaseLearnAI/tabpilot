# App Store Connect：替换构建、填写审核信息、重新提交

- 入口 URL：https://appstoreconnect.apple.com/apps
- 前置条件：用户已在 Chrome 中登录 App Store Connect；新构建已上传并处理完成
- 不可逆动作：**「提交以供审核」/「Add for Review」/「Submit」之前必须停下来，由用户确认**

## 配方（待第一次跑通后补全）
1. 打开 App → 进入待提交的 iOS 版本页
2. 「构建版本」区域：移除旧构建 → 选择新构建
3. 「App 审核信息」：填写登录所需的演示账号和密码、备注
4. 保存 → 停下来，等用户确认后再点提交

## 已知坑
- 在 MiniMax Code 内置浏览器里会一直白屏（独立环境，没有登录态）。改用 TabPilot，在用户自己的 Chrome 里操作
- Apple ID 登录框是跨域 iframe，快照看不到里面的元素，需要用户自己登录（目前也本来就该用户自己登）
